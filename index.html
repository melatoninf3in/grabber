Developers

Deploy with one HTTP call.

Solana posts to /solana/deploy, EVM to /evm/deploy. Bundle, snipe, buy, and sell hit the same endpoints the app uses.

  • Deploy APIQuick-start in the docs. Multipart or JSON, with an image file or URL.↗
  • For agentsFull product context at /llms-full.txt for scripts and automation.↗
POST deploy.shCopy
# Deploy on Pump.fun with a 0.5 SOL dev buy.
# Swap platform for bonk, bags, and the rest.
# EVM pads (four, pons, ...) post to /evm/deploy.

curl -X POST https://rapidlaunch.io/solana/deploy \
  -H "Authorization: Bearer <session_token>" \
  -F "name=My Token" \
  -F "symbol=MTK" \
  -F "platform=pump" \
  -F "buy_amount=0.5" \
  -F "image_url=https://example.com/image.png"
