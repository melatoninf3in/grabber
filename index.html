Overview

Discord Quests are tracked client-side. The browser holds the session state the client uses to report quest progress. QuestPilot reads that state from the tab you are already logged into, asks Discord's own API for the account context, and reports completion.

How it works

Discord's client is a single-page application. Quest progress lives in the browser storage layer and syncs through Discord's own API. QuestPilot is a thin wrapper over that session. It uses the session already present in your tab.

A bookmarklet is a single javascript: URL stored in your bookmarks bar. It runs when clicked, on the current page. It is not a persistent extension and is removed by deleting the bookmark.
